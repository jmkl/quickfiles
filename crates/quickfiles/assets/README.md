# Fonts

`SymbolsNerdFontMono-Regular.ttf` is **required to build** (`src/theme.rs` embeds it).

It is the "Symbols Only" font from Nerd Fonts, used for the file and folder icons:

1. Download `NerdFontsSymbolsOnly.zip` from
   https://github.com/ryanoasis/nerd-fonts/releases/latest
2. Copy `SymbolsNerdFontMono-Regular.ttf` from it into this folder.
   (Keep the zip's `LICENSE` next to it if you distribute the app.)
